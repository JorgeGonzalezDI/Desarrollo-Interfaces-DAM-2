# 01 - POO, Genericos e Interfaces funcionales

Proyecto Maven sin dependencias externas: basta con abrirlo en IntelliJ
y ejecutar `Main.java`.

## Que ensena
- **Herencia y polimorfismo**: `Figura` (abstracta) -> `Circulo`, `Rectangulo`.
- **Encapsulacion e interfaces**: `Libro` implementa `Prestable`.
- **Enums**: `EstadoLibro`.
- **equals() / hashCode() / toString()**: en `Libro`, siguiendo el patron de los apuntes.
- **Genericos**: `Caja<T>`.
- **Interfaces funcionales**: `Biblioteca` usa `Predicate<Libro>`, `Consumer<Libro>` y `Supplier<Libro>`.

## Como ejecutarlo
Abre `Main.java` y pulsa el boton de Run junto a `public static void main`.
Todo el resultado se explica por consola, en el mismo orden que los apuntes.
