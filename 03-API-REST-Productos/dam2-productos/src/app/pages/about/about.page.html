Aplicación hecha con Ionic 9 y Angular 22 (standalone) para la asignatura de Desarrollo de Interfaces. Consume la API REST pública de dummyjson con HttpClient y muestra los productos con estados de carga y error, usando signals para que la pantalla se actualice sola.

Con ella he practicado servicios con inject(), modelos tipados, rutas con carga perezosa, control de flujo con @if / @for y el modo oscuro de Ionic.

Código fuente y resto de prácticas: github.com/JorgeGonzalezDI
